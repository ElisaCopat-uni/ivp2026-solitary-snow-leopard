# IVP2026 - A solitary snow leopard

Project for Image and Video Processing (BCS2710A), Maastricht University.

The goal is to read the time from photos of analogue clocks (Kaggle challenge ivp-2026), using only classical image processing.

## How to run

```bash
python3 -m venv ivp2026
source ivp2026/bin/activate
pip install -r requirements.txt
```

The data isn't in the repo. Download it from Kaggle and put it next to this folder as `ivp-2026/`.
